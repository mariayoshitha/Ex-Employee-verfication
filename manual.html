  1. Open the admin URL Go to https://verify.techteira.com/admin — do not use /admin.php directly (blocked).

  1. Click "+ Add Record" Button is in the top-right area of the dashboard. The add form expands at the top of the list.

Editing a record

  1. Click "Edit" on the rowThe row expands into an inline edit form with all current values pre-filled.
  2. Modify the fields neededChange only what needs updating — all other fields stay as-is.
  3. Click "Save"Changes apply instantly. The audit log records who made the change and when.

Deleting a record

  1. Click "Delete" on the rowA confirmation prompt appears: "Delete this record?"
  2. Confirm the deletionClick OK. The record is permanently removed. This action cannot be undone — check the audit log if needed.
⚠
Deletion is permanent There is no recycle bin. Once deleted, a record cannot be restored unless you re-add it manually or re-upload via CSV. The audit log records that the deletion happened but does not store the full record data.

📄 CSV Bulk Upload AdminLocation User

Upload many records at once using a CSV file. This merges new records into the existing data — it does not wipe the database.

Upload CSV
  1. Download the template Click ⬇ Template. Open the downloaded template.csv in Excel or Google Sheets.
  2. Fill in your data Do not change column headers. Fill each row with one employee. See the Field Reference for allowed values.
  3. Save as CSV In Excel: File → Save As → choose CSV UTF-8. In Google Sheets: File → Download → CSV.
  4. Click "Choose File" and select your CSV The filename appears next to the button.
  5. Click "Upload CSV" A green banner confirms how many records were uploaded. If any rows have errors (missing fields, wrong date format), those rows are skipped and the count reflects only what succeeded.

🔧 Troubleshooting

Upload says success but records don't appear

  1. Check date formatsDates must be YYYY-MM-DD. Rows with wrong date format are silently skipped.
  2. Check for duplicate Employee IDsRows where the Employee ID already exists in the database are skipped. Use Edit to update existing records.
  3. Check location spellingLocation must match exactly (e.g., Kuala Lumpur, Malaysia not KL). Copy from the Field Reference table above.

Login fails — "Invalid credentials"

Password is case-sensitive. Check for extra spaces. If locked out (5 failed attempts), wait 15 minutes or contact your admin to check server temp files.

Session expired — redirected to login

Sessions expire after 30 minutes of inactivity. Log back in — no data is lost, only the session cookie expired.

Forbidden (403) when opening admin URL

Do not navigate directly to /admin.php — use /admin. Same for /api (not /api.php). The server blocks direct PHP file access.

CSV template download doesn't start

The ⬇ Template button links to ?download=template. If nothing happens, check that cookies are enabled (the download requires an active session).

🔒
Never share your password or session URL Sessions are tied to your browser. Do not share the admin URL with query parameters. Always log out when done on a shared machine.
